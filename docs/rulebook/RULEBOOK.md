# 01_CONSTITUTION
FORMA OPUS — DESIGN CONSTITUTION |  |  |  | 
CORE = immutable · SYSTEM = common system · FLEX = brand/project variation |  |  |  | 
Area | Rule | Level | Operational interpretation | Prohibited
Brand Architecture | Visually separate every brand level | CORE | FORMA OPUS → brand → project hierarchy must remain visible. | EXERCITUS as peer of GREA/FORMA OPUS
Brand Architecture | Higher level = more neutral | CORE | Character increases as user enters deeper layers. | Genre motifs on master entry
Visual | Atmosphere before explanation | CORE | Entry prioritizes mark, space, image and motion. | Long intro copy / many CTAs
Layout | Compose screens as spaces | CORE | Viewport-scale sections, focal points, intentional empty areas. | Dense repetitive cards by default
Color | Master UI remains neutral | CORE | Chromatic brand colors appear as identifiers at lower levels. | Multiple master accent colors
Typography | Typography is a primary graphic element | CORE | Clear Display / Heading / Body / Metadata hierarchy. | Too many families or weights
Entry | Entry asks for one action | CORE | FORMA OPUS mark + single entry interaction. | Shop/About/Contact in parallel on first frame
Brand Selection | GREA / PARVUS / MACHINA have equal default rights | CORE | Balanced three-panel default state; difference emerges on interaction. | Default bias toward one brand
Portfolio | Hover portfolio is a sequence, not an ad slideshow | CORE | 3–6 images communicate total → detail → process/structure → completion. | Fast banner-like rotation
Motion | All major transitions mean moving deeper | CORE | Select → emphasize → attenuate surroundings → occupy screen → reveal. | Novel transition per page
Motion | One dominant motion concept per screen | CORE | Foreground or background leads, not both. | Multiple competing major motions
Scroll | Minimize scroll hijacking | CORE | Natural vertical scroll is baseline. | Artificially slowed wheel / forced snapping
Navigation | Back means return to parent space | CORE | EXERCITUS→GREA→Brand Selection semantics. | No clear parent-return path
Project Cards | Project cards must not look like product cards | CORE | Large image + title/number/category; commerce only where approved. | Price/rating/discount/cart in portfolio
EXERCITUS | EXERCITUS visibly derives from GREA | CORE | GREA context appears before or with EXERCITUS. | Direct master-level peer exposure
Responsive | Mobile is recomposed, not scaled | CORE | One strong brand panel at a time; re-set type and spacing. | Tiny desktop three-column layout
Responsive | Touch cannot depend on hover | CORE | Tap/focus/centered-scroll preview alternatives. | Hover-only information
Expansion | New top-level brand requires hub redesign | CORE | Re-evaluate selection layout rather than force-fit. | Fourth brand inserted into unchanged 3-panel layout
Governance | Document every exception | CORE | Reason, scope, end condition, repeatability must be logged. | Silent exceptions
Accessibility | Legibility outranks artistic treatment | CORE | Adequate contrast, readable weights, functional without effects. | Low-contrast body / ultra-thin small text
