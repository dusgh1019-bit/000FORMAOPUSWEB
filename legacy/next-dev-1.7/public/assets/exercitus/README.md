# EXERCITUS asset contract

This directory intentionally contains no production military artwork or garment/equipment GLB yet.

Planned source pipeline:
- 2D authoring master: `.ai` retained for designer ownership/editability.
- 2D web canonical derivative: `.svg`, plus preview `.png`.
- 3D authoring master: `.blend`, `.fbx`, CAD/STEP or other project source as appropriate.
- 3D web delivery: optimized `.glb` with LOD/material metadata.
- Print output: real-size transparent PNG generated from design manifest at production resolution; optional TIFF when printer workflow requires it.
- Every public asset must have rights/source/approval metadata before customer use.
